# P148 AI 輔助學術統計｜教學操作說明

先解壓縮學生版，依資料字典核對欄名及匯入筆數。每次分析記錄檔名、工具與版本、使用的欄位、有效筆數、缺失規則、公式或指令，以及結果。班上可以分組比較 Excel、SPSS、AI-Direct 和 PAL/PAG。

## EXP01｜100 筆平均值

1. 用 Excel 匯入 CSV，確認 `score` 為數值。若欄名在 A1，用 `COUNT(A2:A101)`、`SUM(A2:A101)`、`AVERAGE(A2:A101)` 取得筆數、總和及平均值。Google 試算表可用相同公式。
2. 在 SPSS 匯入時指定首列為變數名稱、`score` 為數值，執行 `DESCRIPTIVES VARIABLES=score /STATISTICS=MEAN SUM STDDEV.`
3. 請 AI-Direct 直接回答同樣的統計量。記下各工具的結果及你對各結果的信心（0–100%），說明信心來自哪些可檢查的證據。

## EXP02｜10,000 筆平均值

重做 EXP01，Excel 範圍改為 `A2:A10001`。先對有效筆數、再對總和、最後對平均值。若工具只能讀取部分資料或無法確認讀取範圍，記錄限制。讓另一組用獨立工具重算，檢查能否得到同一結果。

## EXP03｜同時處理兩種缺失

1. 以 `record_id` 核對 100 列，分別統計空白與 `-99`，並記錄清理後有效筆數。
2. 若 Excel 首列為欄名、分數在 B 欄，可在 C2 輸入 `=IF(OR(B2="",B2=-99),"",B2)`，填到 C101。對 C 欄的資料範圍計算 COUNT、SUM、AVERAGE 與 STDEV.S。
3. SPSS 需將 `score` 匯入為數值，確認空格為系統缺失，再執行 `MISSING VALUES score (-99).`，接著執行 EXP01 的 DESCRIPTIVES 指令。
4. 比較三種結果：排除兩種缺失、只略過空白而保留 `-99`、將兩種缺失改為 0。保留原始 CSV，說明分子與分母如何改變。

## EXP04、EXP05｜獨立樣本 t 檢定

1. 依 `group` 計算各組樣本數、平均數、樣本標準差。畫箱型圖查看兩組分布與離散程度。
2. 以 A 組減 B 組，檢定兩組母體平均數相等的虛無假設。使用雙尾檢定、顯著水準 0.05，比較等變異數 Student t 檢定及不等變異數 Welch t 檢定。記錄平均差、t、自由度、p 與平均差的 95% 信賴區間。
3. SPSS 可執行 `T-TEST GROUPS=group('A' 'B') /VARIABLES=score /CRITERIA=CI(.95).`，比較假設等變異數與不假設等變異數的兩列。Excel 可先將 A、B 的分數分別放入兩欄，再用 `T.TEST(A組範圍,B組範圍,2,2)` 與 `T.TEST(A組範圍,B組範圍,2,3)` 對照雙尾 p 值。完整的 t、自由度及區間可用 SPSS 或 PAL/PAG 取得。
4. 比較兩份資料中的樣本數配置與變異程度，說明你會採用哪種方法及理由。匯報檢定結論時，一併交代平均差與區間。

## AI 操作與繳交

- **AI-Direct**：若介面可以停用程式執行，停用後請模型直接回答。可用提示詞「依附件的完整 CSV 計算指定統計量，回報實際能確認的資料範圍、有效筆數及結果。若無法確認讀取完整檔案，請說明。」若介面實際使用程式或無法判定，記錄工具使用狀態。
- **PAL/PAG**：請 AI 產生讀取 CSV 的 Python 程式。提示中寫明欄位、缺失規則、樣本標準差、雙尾或單尾，以及是否假設等變異數。檢查程式後執行，保留程式、版本與輸出，並用另一工具交叉核對。
- **繳交**：每組提交一張對照表，列出各工具的設定與結果。挑一個結果一致或不一致的例子，說明如何查核、誰能追查，以及再做一次需要保留什麼。
